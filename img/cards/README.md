# Kártyaháttér-képek a főoldalhoz

Ha ide teszel egy képet a megadott néven, a főoldalon a hozzá tartozó kártya háttere halványan ezt mutatja.
Ha nincs kép, a kártya kép nélkül, színátmenettel jelenik meg.

- Formátum: **JPG**, kb. **768 × 512** (fekvő, 3:2), legfeljebb ~150 KB.
- A kép felső részét látni a legjobban (lefelé elhalványul), ezért a lényeg legyen felül vagy középen.
- Bármilyen AI-képgenerátor jó (pl. ChatGPT, Gemini, Copilot / Bing Image Creator, Midjourney). Az alábbi angol promptokat érdemes szó szerint bemásolni.
- Közös stílus minden promptnál: *cinematic digital illustration, dark background, soft neon glow, no text, no letters, no logos*.
